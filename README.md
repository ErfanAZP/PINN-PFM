# PINNs
This repo is dedicated to development of PINNs mainly for phase field models in fracture and multiphysics degradation phenomena.

The aim is to explore data-efficient, differentiable, mesh-free alternatives to conventional numerical methods such as FEM for solving coupled mechanical, chemical, and fracture processes. This is an ongoing project to extend the capability of model to multiphysics problems, such as thermomechanical processes, corrosion, and hydrogen diffusion.
